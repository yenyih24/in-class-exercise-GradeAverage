This Java program calculates and displays the average of three grades entered by the user. 

Here's what the program does step by step:

- Imports the Scanner class: Used to read input from the user.
- Initializes variables: Declares three variables (grade1, grade2, and grade3) to store the grades and one variable (average) to store the calculated average.
- Prompts for input: Asks the user to enter grades for three subjects and reads the input using the Scanner.
- Calculates the average: Adds the three grades and divides the sum by 3 to compute the average.
- Displays the result: Prints the calculated average grade to the console.
